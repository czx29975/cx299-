方式二 · 数据只留本机

在自己电脑上跑

  1. 下载这个仓库（GitHub 上点 Code → Download ZIP，解压）；
  2. 确认装了 Python 3.10+，双击根目录的 启动安语.cmd；
  3. 浏览器打开 http://127.0.0.1:8080/，用账号登录。

首次启动会进入设置向导，建老人档案和三个账号；数据全部留在本机，不经过任何服务器。

三个界面，一套后端

老人端语音/文字对话、确认吃药、记血压、一键求助、守护聆听
家属端看告警与周报、代确认用药、留言、紧急联系人、授权管理
社区值守台工单接单/到场/结案、声光报警、逐级外呼、AI 值守

技术栈：Python 3 标准库 HTTP 服务 + SQLite，零第三方依赖；前端原生 HTML/CSS/JS，可「添加到主屏幕」当 App 用。

为什么不能直接放 GitHub Pages

GitHub Pages 只发静态文件。而安语的登录、工单、用药记录、短信验证码、电话外呼，全部由 app/server.py + SQLite 在服务端完成——静态托管没有后端，页面打不开、/api/* 一律 404。所以在线版是部署在能跑 Python 的托管环境里的，不是静态页。

线上版本怎么更新

  • 改完 app/ 里的代码，把改动同步进上线包 cloud/；
  • 重新发布，分享链接不变，内容被覆盖；
  • 在线实例会读环境变量 PORT 并绑 0.0.0.0，HTTPS 由平台代理负责，容器时区按东八区处理。

线上是独立的一份数据：和本机那份不互通，线上新增的内容不会回流到本机。正式给家人前务必改掉演示密码。
